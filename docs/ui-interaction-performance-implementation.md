## 剩余候选项最终处理

| 候选做法 | 本轮结果 | 原因与边界 |
| --- | --- | --- |
| C1 取消侧栏占位宽度动画、固定/收起后跳变布局 | 不采用，保留现有动画 | 190ms 动画中的中间几何状态是当前交互效果的一部分；取消布局过渡会改变可见行为，与“样式和交互不变”冲突。没有声称此路径已得到性能提升 |
| C2 虚线 Canvas 改静态图片或换绘图后端 | 不采用，保留现有虚线 | 当前按尺寸/颜色/半径变化重画，没有持续定时绘制；替换可能改变缩放时的虚线、圆角与抗锯齿。本轮采用已验证的波浪循环优化 |
| C3 全面改成虚拟列表 | 采用减少隐藏控件的替代方案 | 已获得创建成本和对象数量下降，且保持精确内容高度、滚动范围和像素。文本行仍全部创建，极长内容仍有 O(n) 成本；不宣称已虚拟化 |
| C4 任意结构变更增量 diff | 采用有限的同行更新方案 | 保留结构变化时已有稳定路径，避免引入树重排/滚动锚点新规则。32 行上限控制信号数量，并非所有机器的最优阈值 |
| C6 异步设置保存 | 采用相同内容免写的替代方案 | 保留调用方对同步成功/失败返回值的依赖 |
| C6 日志跟尾合并、滚轮交接重写 | 不采用，保留现状 | 日志原有批量刷新；改变跟尾时机或滚轮传播可能改变用户操作。本轮未复现必须改动的交互缺陷，也未声称这两处有测得的优化收益 |

结论：本轮五项不改变既有视觉设计的优化已完成；上述未采用的候选改造没有实施，不应算作“全部候选代码均已修改”。

## 本机定向 A/B 结果

基线为 `025709d`（包含第一阶段），比较第二阶段修改。环境为 **macOS / PySide6 / Qt 6.11.2 / offscreen / software / Basic**，三轮独立进程对比，项目列表等场景交替执行前后顺序；下表取三轮中位数。样本均为临时合成数据，没有打开用户项目或运行实际业务任务。

| 场景 | 修改前 | 修改后 | 变化 |
| --- | ---: | ---: | --- |
| 10,000 行项目列表单行详情刷新 | 2.1324 ms | 0.9272 ms | 约减少 56.5%；40 次 reset → 0 次 |
| 30,000 条提醒循环切换三个分类 | 7.0609 ms | 5.4415 ms | 约减少 22.9% |
| 重复点击当前提醒分类 | 1.9819 ms | 0.0004 ms | 40 次 reset → 0 次；极短耗时仅作参考 |
| 相同设置重复保存 | 0.1410 ms | 0.0192 ms | 约减少 86.4%；40 次 replace → 0 次 |
| 10 行更新记录创建 | 2.012 ms | 1.287 ms | 约减少 36.0% |
| 1,000 行更新记录创建 | 133.876 ms | 72.341 ms | 约减少 46.0%；可视对象树节点 10,017 → 4,011 |

分类缓存额外持有已访问类别的行引用，最坏为 O(n) 个引用，不复制提醒字典；模型在真正切换分类时仍会规范化行。性能提升没有被表述为整体 FPS 提升或每台机器上的保证值。
